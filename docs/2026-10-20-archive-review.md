## 실제 검증

- 58편 각각의 요약·접기·세 관점 이동과 실제 검색 결과를 조작했습니다. 성경 본문은 모두 ASIDE입니다.
- 58편을320px·22px글자·다크 화면으로 확인했습니다. 1,821표 셀 전부 열 제목을 갖추고 셀 잘림·문서 가로 넘침은0입니다.
- 누가복음 세 편은390px에서 제목36/800, 카드21/700, 본문18/400, 캡션14/400과 행간·색상까지 일치합니다. 데스크톱 제목48·카드23도 대조했습니다.
- localhost 원본에 넣은 테스트용3메모와 체크가 개정본에서 유지됐고 테스트 값만 정리했습니다. 실제 공개 사용자 메모는 읽거나 바꾸지 않았습니다.
- 인쇄용 실제 CSS에서 전체 카드 열림·본문·표·흰 배경·검은 글자를 확인했습니다. 실물 페이지 나눔과 브라우저가 제공하지 않은 다운로드 완료 이벤트는 검증으로 세지 않았습니다.
- 로컬 회귀 검사108개 중107통과·1환경제외. 취소된 중간 Pages 작업은 성공한 main후속 커밋의 Git 조상 관계와 공개 파일·허브·검색 일치까지 확인해야 완료됩니다.
- 공개58HTML은 모두 최종 검토 파일과 바이트가 일치하고 허브·전체 검색 본문도 일치합니다.

# BNOC · 말씀 아카이브

https://laguna821.github.io/BNOC/

## 새 자료 올리기

1. 기존처럼 `YYYY/MMDDYYYY/파일이름.html`에 HTML과 필요한 이미지 파일을 올립니다.
2. 문서에 정확한 `<title>`을 넣습니다. 선택적으로 `<meta name="description" content="자료 소개">`를 넣으면 목록 설명에 사용합니다.
3. main에 반영되면 Actions가 검색 색인, 목록, RSS, sitemap, 최신 자료 링크를 만들고 GitHub Pages에 게시합니다.

2026-10-18 이후 날짜의 새 HTML에는 SameTone Lite 원본 가변 폰트(100–900)와 Noto Serif 그리스어·히브리어 보완 폰트가 자동 내장됩니다. 배포된 HTML을 저장하면 글꼴도 함께 보관됩니다. 원본 Git 파일은 빌드 과정에서 수정하지 않습니다.

기존 `.study-card` + `.prose` 형식에는 `web/editorial.css` 정보 위계가 추가됩니다. 임의 레이아웃은 글꼴만 적용합니다. 같은 완성도를 재현하려면 오늘 자료의 구조와 클래스, 화면/인쇄 스타일을 템플릿으로 사용하고 본문·날짜·이미지·다운로드 파일명을 바꾸세요. 슬라이드 등 스타일을 보존해야 하는 문서는 `<meta name="bnoc-style" content="original">`로 자동 적용을 제외할 수 있습니다. 이미 완성된 SameTone 편집본은 중복 적용하지 않습니다.

## 편집 기준

- 큰 제목 800, 구역·카드 제목 700, 강조 600, 인용 500, 본문 400, 장 번호 200.
- 본문 18px / 행간 1.85, 카드 제목 23px, 구역 제목 30px, 큰 제목 48px.
- 의미 없는 색상 강조를 줄이고 본문·보조 정보·브랜드 색상을 분리합니다.
- 인쇄 규칙은 원문이 담당합니다. 글꼴의 원본 라이선스는 `web/assets/FONT-LICENSES.txt`에 보관합니다.

## 개발

```sh
python scripts/build_site.py
python -m unittest discover -s scripts -p 'test_*.py'
```

Python 표준 라이브러리만 사용합니다. `_site/`만 게시되며 저장소·개발 파일은 배포하지 않습니다. 검색은 제목·소개·성경 이름·전체 본문을 대상으로 하고 연도/성경 필터 및 정렬을 함께 적용합니다. JavaScript 없이도 전체 자료 링크가 표시됩니다.

기존 주소는 유지합니다. 과거 끝에 점이 붙은 파일은 저장소 원본을 보존하고 배포 시 정상 확장자 별칭도 생성합니다. `2025/10122005`의 날짜 표기는 상위 연도 2025를 기준으로 2025-10-12로 처리합니다. 폴더와 원본 이름은 바꾸지 않습니다.

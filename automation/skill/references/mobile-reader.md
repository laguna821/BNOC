# 모바일 읽기 규약

표 제목(caption)도 각 표의 실제 너비로 읽혀야 한다. 모바일에서 table을 block으로 바꿀 때 caption을 table-caption으로 남기면 브라우저가 폭을 한 글자로 계산할 수 있다. 320/390px·22px에서 caption의 폭과 첫/마지막 글자, 행 제목과 셀 내용을 함께 확인한다.

해석과 충분한 서술이 우선이라는 원칙은 모바일 가독성이나 읽기 도구를 생략해도 된다는 뜻이 아니다. 2026-10-18 최신본의 세로형 원어 표와 고정 하단 도구를 기능 기준으로 삼는다. 목차·문단·그림 수는 본문에 맞게 달라질 수 있다.

## 표

- 원어/음역·문법·문맥·대표 용례를 작은 화면에서 한 항목씩 세로로 읽는다. 각 셀에는 실제 열 제목을 붙인다. 비교표도 MT/LXX/NT와 해석의 구별이 유지되어야 한다.
- 히브리어의 RTL과 원어 폰트를 유지한다. 열 제목은 한국어 LTR로 읽힌다. 임의로 요약하거나 단어를 생략하지 않는다.
- 문서 전체 overflow가 없다는 검사만으로 통과하지 않는다. 실제 320px와 390px에서 22px 글자로 표의 첫 항목과 마지막 항목, 각 열의 끝까지 읽는다. 셀/표 폭이 화면 안에 있는지, 열 제목이 내용과 맞는지 확인한다.
- 데스크톱과 인쇄에서는 표의 비교 관계를 유지한다. 병합 셀이나 중첩 표는 실제 결과를 개별 검사하고, 해석 관계를 잘못 표시하면 게시하지 않는다.

## 읽기 도구

- 장문의 어느 위치에서도 목차·찾기, 요약 보기, 전체 접기/펼치기, 맨 위로를 사용할 수 있어야 한다. 모바일 하단 여백과 safe area를 확보해 마지막 문장이 도구에 가리지 않도록 한다.
- 서술형 배치도 개별 제목을 눌러 접고 펼칠 수 있다. 기본값은 펼침이며, 이 기능 때문에 원고를 일정한 길이로 나누지 않는다.
- 요약에서는 저자가 쓴 summary를 읽고 자세히 보기로 원문에 돌아온다. 전체 접기는 해설에만 적용한다. 성경은 독립 ASIDE로 항상 펼친다.
- 빈 검색창에서는 목차 역할을 하고, 검색에서는 본문과 해설을 찾는다. 접힌 글/요약 중 검색 결과를 선택하면 해당 해설을 펼쳐 자세한 본문으로 이동한다. 검색창 닫기/Escape 뒤 조작 위치로 돌아오는지 확인한다.
- 인쇄에서는 해설 전체를 펼치고 요약·접기 상태와 하단 도구를 인쇄하지 않는다. 인쇄 후 기존 읽기 상태를 복원한다.

## 검토와 기존 게시글

review.json의 mobileTables와 readerControls는 별도 필수 검사다. 실제 측정값·항목·동작을 적고 미실시는 통과시키지 않는다. 테스트 fixture의 성공을 실제 원고의 가독성 심사로 기록하지 않는다.

조립 시 reader_layout.audit가 하단 도구의 중복·누락, 검색창 구성, 항상 펼친 성경, 해설별 본문·작성된 요약, 모바일 표의 열 제목 누락을 별도로 차단한다. 자동 구조 검사 통과는 320/390px·22px에서의 실제 읽기와 기능 검수를 대신하지 않는다. 본문별 구성이나 그림 수를 정하는 검사도 아니다.

적용 범위를 구별한다. 새 렌더러 또는 공통 기능을 갱신해도 기존 독립 HTML 전체가 자동으로 바뀌지 않는다. 개정한 글은 공개 URL에서 확인하고, 미개정 글은 목록에 남겨 각 글을 검토할 때 함께 적용한다. 공통 읽기 기능 적용과 신학적 내용 검토의 완료 상태를 합쳐 기록하지 않는다.

이미 게시된 reader 1.1 문서는 reader_layout.upgrade로 읽기 기능만 갱신할 수 있다. 함수는 작성된 본문·요약·원어/방향·성경 절·출처 링크·이미지의 동일성을 확인하고 다르면 거절한다. 공개 원본 해시와 새 HTML 해시, 실제 브라우저 검수 근거를 별도의 갱신 기록으로 묶은 뒤 게시한다. 과거 신학 검토가 새 UI 검토를 대신하지 않는다.
